# OnlyOnePenIt

小さなアトリエで、文房具の消耗を楽しみながら描くペイントシミュレーションです。

## 起動

静的サイトです。リポジトリのルートで次を実行し、表示された URL を開いてください。

```sh
python -m http.server 8000
```

## 遊び方

原始的なペイントツール（リアルペイントシミュレーション）です。最初に使えるのは鉛筆・シャーペン・消しゴムだけ。道具はすべて実物らしく消耗し、なくなれば文房具屋さんで買います。

- **鉛筆（1本50円）**: 芯の硬さ H／HB／B／2B を選べます。硬いと薄く長持ち、柔らかいと濃く消耗が激しい。使うほど先が太くなり、太くなりすぎると書けなくなります。鉛筆削り（お手入れ）で長さを消費して鋭く戻せます。重ね描きで濃くなり、短くなりすぎると線がブレて、やがて使えなくなります。
- **シャーペン**: 芯がすり減ると書けなくなるのでノックして出します。好きなだけノックできますが、出しすぎると折れやすくなり、折れると出ていた分を失います。本体の芯が尽きたら芯交換（替芯 H／HB／B／2B は20本100円、色つき芯は15本100円）。硬い芯ほど紙に跡（溝）が残りやすく、消してもうっすら残ります。
- **消しゴム**: 普通（30円）／かたい（50円）／すごい（100円）／色鉛筆用（50円）。4つの角を切り替えて使え、角は使うほど丸くなって消す範囲が広がります。一定確率で折れて残量半減。濃いものを消すほど早く「黒消しゴム状態」になり、黒いにじみをつけるようになります（角ごと判定、こすり続けると解除）。完全に消すには何度かこする必要があります。ペン型（100円で解放、替えゴム5個100円）と電動（200円で解放、替えゴム10個100円・電池別）もあります。
- **色鉛筆（9色・1本100円）** は色鉛筆用消しゴムでないと消えません。**ボールペン（5色・100円）** は修正テープ（100円）／修正液（200円）でしか直せません。テープの上にはボールペン以外描けません。**筆（太／細／平・100円）と絵の具（4色・100円）** は描くたび絵の具をつけ直し、絵の具は消せません。パレット（100円）で混色、バケツ（100円）で希釈ができます。**定規（100円）** と **コンパス（200円、鉛筆依存）** もあります。
- **紙**: A4／A5／A6／B4／B5／B6 は100枚100円、指定サイズは100枚2,000円。初期配布は鉛筆HB・シャーペン・替芯10本・普通の消しゴム2個・A4の紙100枚です。
- **消しカス**: ドラッグで動かせ、2つを同じ位置でこするとまとまって大きくなります。ゴミ箱に捨てるとお金になり、大きいまとまりほど割がよくなります。
- **家電量販店**: 所持金が10,000円を超えると出現し、液タブが100,000円で売られています。買うとゲームクリア（他のペイントツールへの案内付き）。
- 取り消し／やり直し・PNG保存・自動保存（ブラウザ）対応。描画や消しカス操作の取り消しでは消耗も戻りますが、購入・お手入れ・換金・紙交換で履歴は消えます。

## 補足

- 上部の「あそびかた」から操作方法を確認できます。タッチ操作にも対応しています。
- 日本語表示用に Noto Sans JP の必要な文字のサブセットを同梱しています。ライセンスは `assets/fonts/LICENSE.txt` を参照してください。
- 描画と消しカスの形・動きは実物をモデルにした近似表現で、物理シミュレーションそのものではありません。
