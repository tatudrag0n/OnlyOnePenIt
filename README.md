# OnlyOnePenIt

小さなアトリエで、文房具の消耗を楽しみながら描くペイントシミュレーションです。

## 起動

静的サイトです。リポジトリのルートで次を実行し、表示された URL を開いてください。

```sh
python -m http.server 8000
```

## 遊び方

- 道具箱から鉛筆、シャーペン、消しゴム、定規を選び、紙の上をドラッグします。色鉛筆、ボールペン、絵筆は文房具屋さんで購入できます。
- 右側で色（カスタムカラーにも対応）・線の太さ・濃さを調整できます。定規はドラッグ中に線をプレビューします。ペン入力では筆圧に対応します。道具は使うと消耗し、お手入れや補充にお金がかかります。
- 描いた部分を消しゴムで消すと消しカスがたまります。「手で集める」を選んで紙の上でドラッグし、消しカス同士をぶつけてまとめます。「まとまりをゴミ箱へ」で、まとまった分だけお金に換えられます。消しカスは絵とは別の層にあり、PNGには入りません。
- キャンバス上部から取り消し・やり直し・PNG保存・新しい紙への交換ができます。描画や消しカスを動かした操作の取り消しでは、その操作に伴う消耗や消しカスも戻ります。購入・お手入れ・換金・紙の交換を行うと取り消し履歴は消えます。
- 絵、消しカスの位置とゲームの状態はブラウザに自動保存されます。紙を交換すると、紙に残った消しカスもなくなります。ブラウザのデータを消すと保存も消えるため、大切な作品はPNGで保存してください。
- 文房具屋さんでは種類ごとに商品を見て、かごに入れてからまとめてお会計できます。♡で欲しいものを1つ目標に設定できます。お会計前なら数量を変更・削除できます。かごの内容はページを閉じると消えますが、目標は保存されます。
- 所持金が10,000円に達すると、液晶ペンタブレットの購入が解放されます。一度解放されれば、その後所持金が減っても解放されたままです。100,000円で購入するとゲームクリアです。

## 補足

- 上部の「あそびかた」から操作方法を確認できます。タッチ操作にも対応しています。
- 日本語表示用に Noto Sans JP の必要な文字のサブセットを同梱しています。ライセンスは `assets/fonts/LICENSE.txt` を参照してください。
- 描画と消しカスの形・動きは実物をモデルにした近似表現で、物理シミュレーションそのものではありません。
